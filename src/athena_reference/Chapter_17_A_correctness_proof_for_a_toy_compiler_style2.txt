17.1.4 Compiling numeric expressions
We are ﬁnally ready to deﬁne the compiler. It takes an arithme tic expression and returns a
program in the machine language of the previous section that will (hopefully) compute the
value of the expression:

[(compile const n = (push n)::[])
(compile (e1 + e2) = compile e2 ++ compile e1 ++ [add])

(compile (e1 * e2) = compile e2 ++ compile e1 ++ [mult])

17.1.5 Correctness
Is this simple compiler correct? What does correctness mean in this context? As with all
compilers, correctness here means that the semantics of the target program are the same,
in some appropriate sense, as the semantics of the source tex t. In this case, the semantics
of the source expression are given by the interpreter I, while the semantics of the compiled
program are given by exec. Accordingly, to say that the two semantics are the same mean s
that if we apply the virtual machine to the compiled program w e will obtain the same result
that we would get by applying the interpreter Ito the source expression:
define compiler-correctness := (forall e . run-vm compile e = I e)
We can express this condition graphically as follows:
Expression e Program p
Result ncompile
evaluateRun virtual machine
A diagram of this form is known as a commuting diagram . In such a diagram, every directed
arc represents a function (or a morphism , in alternative terminology). The idea is that the
function compositions represented by any two directed path s from the same starting point
to the same destination are identical functions, i.e., they produce the same results when
applied to the same arguments.
Socompiler-correctness is the property that we ultimately need to prove. Since this
property is universally quantiﬁed over all expressions, we will go about it by way of struc-
tural recursion on expressions. A bit of experimentation wi ll reveal that, as stated, the
property is not quite suitable for induction. The semantics of our machine language are
given in terms of exec, which takes a stack as an explicit second argument, and we ne ed to
take that into account. We may thus deﬁne the property to be pr oven inductively as follows:
