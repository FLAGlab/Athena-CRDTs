\chapter{Formal CRDT Theory and Semilattice Foundations}\label{chap:theory}

\section{Introduction}

This chapter presents the formal mathematical foundations of CRDTs based on join-semilattice theory. We show how semilattice properties guarantee Strong Eventual Consistency (SEC) and provide formal proofs for specific CRDT instances.

\section{Join-Semilattices}

A join-semilattice is an algebraic structure $(S, \sqcup)$ consisting of a set $S$ and a binary operation $\sqcup: S \times S \to S$ satisfying three axioms:

\begin{definition}[Join-Semilattice]
A join-semilattice is a structure $(S, \sqcup)$ where $\sqcup$ is:
\begin{enumerate}
  \item \textbf{Commutative}: $\forall x, y \in S. \; x \sqcup y = y \sqcup x$
  \item \textbf{Associative}: $\forall x, y, z \in S. \; (x \sqcup y) \sqcup z = x \sqcup (y \sqcup z)$
  \item \textbf{Idempotent}: $\forall x \in S. \; x \sqcup x = x$
\end{enumerate}
\end{definition}

These three properties (collectively ACI) are fundamental to CRDT convergence. Intuitively:
\begin{itemize}
  \item \textbf{Commutativity} ensures merge order doesn't matter
  \item \textbf{Associativity} ensures grouping doesn't matter
  \item \textbf{Idempotence} ensures duplicate merges are harmless
\end{itemize}

\subsection{Formal Specification in Athena}

We encode the semilattice axioms in Athena as an abstract module:

\AthenaCode{lst:semilattice-theory}{Join-semilattice axioms}
\begin{lstlisting}[language=Athena,style=athena]
module JoinSemilattice {
  declare join: (T) [T T] -> T [200]
  
  assert* join-commutative := 
    (forall ?x ?y . (join ?x ?y) = (join ?y ?x))
  
  assert* join-associative := 
    (forall ?x ?y ?z . 
      (join (join ?x ?y) ?z) = (join ?x (join ?y ?z)))
  
  assert* join-idempotent := 
    (forall ?x . (join ?x ?x) = ?x)
}
\end{lstlisting}

\section{Abstract CRDT Specification}

Building on semilattice foundations, we define an abstract CRDT with five core axioms:

\begin{definition}[Abstract CRDT]
A CRDT is a structure $(S, V, \mathit{initial}, \mathit{update}, \mathit{merge})$ where:
\begin{itemize}
  \item $S$ is the state sort (semilattice elements)
  \item $V$ is the value sort (update operations)
  \item $\mathit{initial}: () \to S$ returns the bottom element
  \item $\mathit{update}: S \times V \to S$ applies updates
  \item $\mathit{merge}: S \times S \to S$ is the semilattice join
\end{itemize}
satisfying five axioms.
\end{definition}

\subsection{The Five CRDT Axioms}

\AthenaCode{lst:crdt-axioms}{Abstract CRDT axioms}
\begin{lstlisting}[language=Athena,style=athena]
module AbstractCRDT {
  domain (State T)
  domain (Value V)
  
  declare initial: (T) [] -> (State T)
  declare update: (T V) [(State T) (Value V)] -> (State T)
  declare merge: (T) [(State T) (State T)] -> (State T)
  
  # Axiom 1-3: Merge is ACI (inherited from semilattice)
  assert* merge-commutative := 
    (forall ?s1 ?s2 . (merge ?s1 ?s2) = (merge ?s2 ?s1))
  
  assert* merge-associative := 
    (forall ?s1 ?s2 ?s3 . 
      (merge (merge ?s1 ?s2) ?s3) = (merge ?s1 (merge ?s2 ?s3)))
  
  assert* merge-idempotent := 
    (forall ?s . (merge ?s ?s) = ?s)
  
  # Axiom 4: Initial state is bottom element
  assert* initial-identity := 
    (forall ?s . (merge initial ?s) = ?s)
  
  # Axiom 5: Updates are monotonic
  assert* update-monotonic := 
    (forall ?s ?v . (merge ?s (update ?s ?v)) = (update ?s ?v))
}
\end{lstlisting}

These five axioms are sufficient to prove Strong Eventual Consistency~\cite{shapiro2011conflict}.

\section{Concrete CRDT Instances}

We now show how specific CRDTs instantiate the abstract theory.

\subsection{GCounter Theory}

A GCounter (Grow-only Counter) uses component-wise maximum as its join operation.

\begin{theorem}[GCounter is a Semilattice]
Let $S = \mathbb{N}$ (natural numbers) and $\mathit{merge}(s_1, s_2) = \max(s_1, s_2)$. Then $(S, \mathit{merge})$ forms a join-semilattice.
\end{theorem}

\begin{proof}
We prove each axiom by reduction to properties of \texttt{N.Max}:

\textbf{Commutative}: By !chain proof:
\begin{align*}
\mathit{gc-join}(n_1, n_2) &= \texttt{N.Max}(n_1, n_2) && \text{[definition]} \\
&= \texttt{N.Max}(n_2, n_1) && \text{[N.Max.commutative]} \\
&= \mathit{gc-join}(n_2, n_1) && \text{[definition]}
\end{align*}

\textbf{Associative}: Similarly via \texttt{N.Max.associative}.

\textbf{Idempotent}: Similarly via \texttt{N.Max.idempotent}.

\textbf{Identity}: $\mathit{gc-join}(0, n) = n$ via \texttt{N.Max.zero-left}.
\end{proof}

The formal Athena proof is in \texttt{src/framework/theory/gcounter\_theory\_v3.ath}, which creates a renaming adapter that inherits all semilattice theorems automatically.

\subsection{GSet Theory}

A GSet (Grow-only Set) uses set union as its join operation.

\begin{theorem}[GSet is a Semilattice]
Let $S = \mathcal{P}(E)$ (power set of elements) and $\mathit{merge}(s_1, s_2) = s_1 \cup s_2$. Then $(S, \mathit{merge})$ forms a join-semilattice.
\end{theorem}

\begin{proof}
Standard set union properties:

\textbf{Commutative}: $s_1 \cup s_2 = s_2 \cup s_1$ by definition of union.

\textbf{Associative}: $(s_1 \cup s_2) \cup s_3 = s_1 \cup (s_2 \cup s_3)$ by set theory.

\textbf{Idempotent}: $s \cup s = s$ by set theory.
\end{proof}

The formal Athena proof is in \texttt{src/framework/theory/gset\_theory.ath}.

\subsection{PN-Counter Theory}

A PN-Counter (Positive-Negative Counter) is a product of two GCounters.

\begin{theorem}[PN-Counter is a Semilattice]
Let $S = \mathbb{N}^n \times \mathbb{N}^n$ (pairs of GCounters) and $\mathit{merge}((p_1, n_1), (p_2, n_2)) = (\max(p_1, p_2), \max(n_1, n_2))$ where max is component-wise. Then $(S, \mathit{merge})$ forms a join-semilattice.
\end{theorem}

\begin{proof}
Product of semilattices with pointwise operations inherits all three properties:

\textbf{Commutative}: $(\max(p_1, p_2), \max(n_1, n_2)) = (\max(p_2, p_1), \max(n_2, n_1))$ since max is commutative on both components.

\textbf{Associative}: Follows from associativity of max on both components independently.

\textbf{Idempotent}: Follows from idempotence of max on both components independently.
\end{proof}

The formal Athena proof is in \texttt{src/framework/theory/pncounter\_theory.ath}.

\section{Strong Eventual Consistency}

The semilattice properties directly imply Strong Eventual Consistency.

\begin{theorem}[SEC from Semilattice Properties]\label{thm:sec}
Let $(S, \sqcup)$ be a join-semilattice and let $\mathit{update}: S \times V \to S$ satisfy monotonicity (Axiom 5). Then for any state $s$ and any updates $v_1, v_2 \in V$:
\[
\mathit{update}(\mathit{update}(s, v_1), v_2) \sqcup \mathit{update}(\mathit{update}(s, v_2), v_1) = \mathit{update}(\mathit{update}(s, v_1), v_2)
\]
\end{theorem}

\begin{proof}
By commutativity and monotonicity:
\begin{align*}
& \mathit{update}(\mathit{update}(s, v_1), v_2) \sqcup \mathit{update}(\mathit{update}(s, v_2), v_1) \\
&= \mathit{update}(\mathit{update}(s, v_2), v_1) \sqcup \mathit{update}(\mathit{update}(s, v_1), v_2) && \text{(commutative)} \\
&= \mathit{update}(\mathit{update}(s, v_1), v_2) && \text{(same state, idempotent)}
\end{align*}
\end{proof}

This theorem shows that regardless of the order in which updates are applied, merging the resulting states produces a consistent result.
